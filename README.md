# Grimarillion Mastery Codex

A browsable reference for the [Grimarillion](https://forums.crateentertainment.com/t/rel-grimarillion-v96/46587) mod for Grim Dawn.

**Site:** https://yamahuser.github.io/grimarillion-codex/

- **Mastery Codex** (`index.html`): all 42 masteries and 1,446 skills, with the in-game skill trees, descriptions, mastery requirements, max ranks and per-rank stats, plus search across every skill.
- **Pair Atlas** (`pairs.html`): all 861 two-mastery pairs with the mod's pair titles, synergy tiers, Zenith cross-class bonus skills and attack-replacer conflicts.

## Where the data comes from

The pages were generated from a local install by reading the game and mod database files (`database.arz`, the GDX1–3 expansion databases and `grimarillion.arz`) and the English text archives. Values are each skill's base numbers. In-game tooltips show flat damage higher because they add your character's % bonuses.

The Pair Atlas tiers are a heuristic: they compare damage types, weapon styles and support roles, and are not tested build rankings.
