# Grimarillion Mastery Codex

A browsable reference for [Grimarillion](https://forums.crateentertainment.com/t/rel-grimarillion-v96/46587) for Grim Dawn, extended with the 23 classes from [Dawn of Masteries](https://forums.crateentertainment.com/t/dawn-of-masteries/94373) that Grimarillion does not have (Cataclysm, NCFF, Diablo 2 and others).

**Site:** https://yamahuser.github.io/grimarillion-codex/

- **Mastery Codex** (`index.html`): all 65 masteries and 2,197 skills, with the in-game skill trees, descriptions, mastery requirements, max ranks and per-rank stats, plus search across every skill.
- **Pair Atlas** (`pairs.html`): all 2,080 two-mastery pairs, analysed skill by skill. For each pair it shows the damage skill that gets the most help from the other tree, which partner skills carry it and what they add, how much of each tree is useful, and flags pairs that rely on a single skill. Includes the mod's pair titles and the Zenith cross-class bonus skills.

## Where the data comes from

Generated from a local install by reading the game and mod databases (`database.arz`, the GDX1-3 expansion databases and the merged Grimarillion + Dawn of Masteries database) and their text archives. Values are each skill's base numbers at max rank; in-game tooltips show flat damage higher because they add your character's % bonuses. The pair analysis is a guide built from those numbers, not tested builds.
